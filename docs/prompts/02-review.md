## Что нашлось

Критичных проблем не было. Исправлено три бага:

1. **Ложное сообщение «Каталог пуст».** Список фильтровался по дебаунсенному запросу, а текст пустого
   состояния выбирался по мгновенному значению: сразу после очистки поиска пользователь ~300 мс видел
   сообщение о пустом каталоге при полном каталоге.
2. **Возможная потеря обновления фильтров.** Предыдущие значения брались из замыкания, а не из актуальной
   строки запроса — два обновления в одном тике затёрли бы друг друга.
3. **Поле `image` не проверялось** при чтении корзины из `localStorage` — единственное место, куда
   попадают недоверенные данные.

По согласованию сумма в шапке стала учитывать промокод, чтобы не расходиться с итогом корзины.

Удалён мёртвый код: `EMPTY_FILTERS`, тип `Category`, лишние экспорты `getDiscountCents`, `CartTotals`
и `initialCartState`. Почищен `.gitignore` от наследия Create React App.

## Что проверялось и оказалось чистым

Отладочных вызовов, черновиков и TODO нет; дублей изображений нет; неиспользуемых CSS-классов нет;
`src/services/api.js` и ассеты задания не тронуты — диф по ним нулевой.

Отдельная оговорка про базу сравнения: `master` в форке отстаёт от рабочей ветки на upstream-коммиты
задания, поэтому сравнивать нужно с `59e310f`, а не с `master` — иначе `api.js` выглядит изменённым.
