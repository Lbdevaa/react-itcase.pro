## Этап 1. Инфраструктура

> Переводи шаблон на Vite и TypeScript: конфиги, алиасы по слоям, ESLint с проверкой границ FSD.
> Кода приложения на этом шаге не пишем — только инфраструктура, чтобы baseline не смешался с конфигами.

> React берём 19-й.

Правила границ проверены на файлах-нарушителях: импорт вверх по слоям, импорт соседнего слайса и
импорт во внутренности слайса мимо `index`.

## Этап 2. Baseline

> Генерируй baseline: обязательная функциональность целиком — список товаров с поиском, фильтром
> и сортировкой, детальная страница с галереей и выбором цвета и размера, корзина с сохранением
> в localStorage.

Линтер (`react-hooks/set-state-in-effect`) отверг сброс состояния через `useEffect` — выбор цвета
и размера переписан на производное состояние, сброс при смене товара и цвета сделан через `key`.
Результат проверен в headless-браузере: три страницы, битые ссылки, восстановление корзины.

## Этап 3. Состояние в URL

> Я внёс рефакторинг в проект, ознакомься и делай дальше по плану — этап 3.

Выбранные цвет и размер перенесены в строку запроса хуком `useProductOptions` по образцу
`useProductFilters`. Проверены восстановление по ссылке, очистка размера при смене цвета
и устойчивость к битым параметрам.
